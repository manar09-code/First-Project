# Solar System Explorer

A responsive educational website about the Solar System, built as an early front-end project to practice semantic HTML, CSS layouts, Bootstrap, responsive design, and CSS animations.

## Highlights
- Informational content about Solar System objects
- Responsive layout for desktop and mobile
- CSS Grid and Bootstrap-based layouts
- CSS animations and interactive navigation
- Static front-end project suitable for GitHub Pages

## Tech Stack
- HTML5
- CSS3
- CSS Grid
- Bootstrap 5

## Project Structure
- mini projet/ — main website files
- index.html — main entry point
- style.css — primary styling
- menu.css — navigation and animation styles

## Running Locally
~~~bash
git clone https://github.com/manar09-code/First-Project.git
cd First-Project
~~~
Open the project's index.html in a browser.
